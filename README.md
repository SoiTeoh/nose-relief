# 根治鼻炎通气大师（Nose Relief）

一款基于 **Vite + TypeScript + Matter.js + 原生 HTML5 Canvas 2D + Web Audio API** 的搞笑解压物理小游戏（Idea Lab v2 — Project 05）。  
> 注：纯搞笑解压游戏幽默表达，不作任何真实医疗或治疗效果宣称。

## 核心玩法

- **巨型拟人鼻子双通道**：左右鼻腔由中央鼻中隔隔开，上方对应实时通气率进度条（`0% ~ 100%`）；重度鼻塞时大鼻子委屈流泪，双孔贯通瞬间化身 `★ ▽ ★` 天使幸福脸！
- **4 种 Matter.js 物理堵塞物**：
  - **黏糊鼻涕团（`mucus`）**：Q 弹易抱团，气流或水枪一冲就飞。
  - **打结猫毛团（`hairball`）**：高静摩擦卡在拐角，需要手指搓松或洗鼻水枪降摩冲刷。
  - **刺球花粉（`pollen`）**：停留超过 `4s` 会额外催生小黏液球。
  - **冷空气冰块（`ice`）**：大块卡死且升高同侧摩擦，可用薄荷爆弹或黄金蓄力猛擤直接震碎！
- **疏通三件套**：
  - 👆 **鼻腔内直接划动搓揉**：给局部堵塞物施加物理搅动与下滑力。
  - 😤 **按住蓄力猛擤（`Space`）**：`0.55s ~ 1.0s` 黄金区松手爆出高压脉冲；死憋超过 `1.5s` 过载耳鸣。
  - 💦 **洗鼻水枪（`1`） & ❄️ 薄荷爆弹（`2`）**：定点盐水冲刷低通气侧，或全通道碎冰清凉解除粘连。
- **双孔贯通 & 窒息危机**：两侧同时 `≥ 85%` 触发 `3.5s`「神清气爽 ×3」狂飙得分；两侧同时 `< 18%` 触发 `4.5s` 窒息倒计时（任一侧恢复 `≥ 22%` 即解除）。
